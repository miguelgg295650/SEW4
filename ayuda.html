Ayuda para MotoGP Desktop

MotoGP Desktop es una aplicación web informativa y educativa que permite consultar información relacionada con el campeonato de MotoGP, sus pilotos, circuitos, condiciones meteorológicas, clasificaciones y juegos interactivos.

Navegación general

La navegación por MotoGP Desktop se realiza mediante el menú principal situado en la parte superior de la página. Desde él se puede acceder a todas las secciones del sitio.

  • Inicio: página principal del proyecto.
  • Piloto: información detallada sobre el piloto Brad Binder.
  • Circuito: datos del circuito, altimetría y visualización del trazado en un mapa dinámico.
  • Meteorología: previsión meteorológica para el circuito.
  • Clasificaciones: resultados de carrera y clasificación del mundial obtenidos desde un documento XML.
  • Juegos: juegos interactivos y acceso al test de usabilidad.
  • Ayuda: explicación del funcionamiento de la aplicación.

Sección Piloto

En esta sección se muestra información relevante sobre el piloto Brad Binder, incluyendo su trayectoria deportiva, títulos conseguidos y resultados más destacados en MotoGP.

El contenido es estático y se presenta utilizando una estructura semántica HTML adecuada.

Sección Circuito

La sección de circuito permite cargar distintos archivos para visualizar información específica del trazado:

  • Archivo HTML: muestra información descriptiva del circuito.
  • Archivo SVG: representa la altimetría del circuito.
  • Archivo KML: visualiza el recorrido del circuito sobre un mapa dinámico.

Cada archivo se carga de forma independiente y su contenido se muestra en la sección correspondiente sin afectar al resto de la página.

Sección Meteorología

En esta sección se consulta la previsión meteorológica asociada al circuito, obteniendo datos como temperatura, estado del tiempo y condiciones atmosféricas.

La información se obtiene desde un servicio externo y se presenta de forma clara para el usuario.

Sección Clasificaciones

La sección de clasificaciones muestra información obtenida desde un documento XML almacenado en el servidor, incluyendo:

  • Ganador de la carrera.
  • Tiempo total empleado.
  • Clasificación del mundial tras la carrera.

Los datos se procesan mediante PHP y se presentan usando una estructura HTML sencilla.

Juegos

En la sección de juegos se incluyen distintos elementos interactivos, como el juego de memoria con cartas o los cronometros.

Juego de cartas

El juego de cartas consiste en un juego de memoria donde el usuario debe encontrar parejas de cartas iguales. El juego se desarrolla mediante JavaScript y ofrece una experiencia interactiva.

Requisitos técnicos

Para el correcto funcionamiento de MotoGP Desktop es necesario:

  • Tener habilitado JavaScript en el navegador.
  • Acceder a la aplicación mediante un servidor web (por ejemplo, XAMPP).
  • Disponer de soporte para PHP y base de datos MySQL.
